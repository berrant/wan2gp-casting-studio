# Security and private reporting

Casting Studio is a locally installed community plugin, not a hosted generation service. Use it on a trusted WanGP installation with appropriate authentication and network restrictions. Do not expose the plugin directly to the public internet. Local consent controls and reference checks are aids, not guarantees of authorization or security.

Report security vulnerabilities through the repository's [Security advisories](https://github.com/berrant/wan2gp-casting-studio/security/advisories) page using **Report a vulnerability**, if private vulnerability reporting is enabled. If it is not available, open an issue asking for a private contact method without providing vulnerability details. Do not post secrets, private paths, raw logs, databases, photos or exploit details in a public issue. Use synthetic reproduction data and the installed plugin/host version. No response-time guarantee is made.

For copyright, privacy or likeness concerns about project-distributed material, request a private contact method through the repository's [issue tracker](https://github.com/berrant/wan2gp-casting-studio/issues). Provide only a brief, nonsensitive description in public. Do not submit intimate imagery, private identity information, or copies of the affected person's images. The maintainer does not receive or control independently operated local installations or their outputs; report unlawful published content to the relevant hosting platform. GitHub has its own [copyright reporting process](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy) for material hosted there. This procedure is not an assertion of statutory safe-harbor status or a promise to remove files from third-party installations.

Server-side image fetching uses checked public numeric addresses and original hostname TLS verification. Redirects and environment proxies are disabled for these fetches. Browser remote previews and external dependency requests are separate network paths; no claim of comprehensive SSRF protection or multi-user isolation is made. Do not place secrets in source URLs; reference exports can include recorded source URLs.
